# METRICS.md: PTQ Error Propagation in Codec-LMs

This document defines the core metrics used to analyze how numerical perturbations from Post-Training Quantization (PTQ) propagate through autoregressive neural codec generation, ultimately leading to perceptual speech degradation. 

Instead of relying solely on downstream metrics like Word Error Rate (WER), these metrics isolate the exact causal chain of token divergence.

---

## 1. First Divergence Position (FDP)

**Formula:**
$$FDP = \min_t \{t : y_t^{PTQ} \neq y_t^{FP}\}$$

Where:
*   $t$ is the generation step (token position).
*   $y_t^{PTQ}$ is the token generated by the quantized model at step $t$.
*   $y_t^{FP}$ is the token generated by the full-precision baseline model at step $t$.

### The Question it Answers
**"When does quantization cause the model to drift from the baseline's generation path?"** 

Specifically, FDP identifies the exact moment the numerical error introduced by quantization becomes large enough to alter the top-1 predicted token.

### How it Captures the Answer
By performing a step-by-step comparison of the token sequences generated by both the $FP$ and $PTQ$ models given the same prompt, FDP isolates the very first index of mismatch. 

*   **Mechanism:** It ignores overall sequence accuracy and focuses entirely on the model's breaking point. 
*   **Significance:** A higher FDP indicates the quantized model is highly faithful to the original model's decision-making process for longer durations. A very low FDP means quantization immediately disrupted the token probabilities.

---

## 2. Cumulative Divergence Rate ($D(t)$)

**Formula:**
$$D(t) = \frac{1}{t} \sum_{i=1}^t \mathbf{1}[y_i^{FP} \neq y_i^{PTQ}]$$

Where:
*   $\mathbf{1}[condition]$ is an indicator function that returns 1 if the condition (a token mismatch) is true, and 0 otherwise.
*   $t$ is the current generation position.

### The Question it Answers
**"Does one changed token cause catastrophic divergence, or do errors remain isolated?"**

Because these are *autoregressive* models, a single incorrect token is fed back into the model to predict the next token. This metric reveals whether that initial error (the FDP) cascades into total sequence failure or if the model recovers.

### How it Captures the Answer
$D(t)$ calculates the running average (or error density) of mismatched tokens up to position $t$. By plotting $D(t)$ across the length of the generated sequence, you can observe the propagation behavior:

*   **Mechanism:** If $D(t)$ remains at 0 until the FDP and then sharply accelerates upwards, it proves that a single token mismatch throws the autoregressive generation off the original manifold, causing catastrophic divergence. 
*   **Significance:** If $D(t)$ remains relatively low or flat after the initial FDP, it suggests the model's codec structure is robust to minor token variations. If it spikes, it proves that token-level PTQ errors compound rapidly.

---

## Summary of Metric Roles

| Metric | Role in the Causal Chain | What it Measures |
| :--- | :--- | :--- |
| **FDP** | The Trigger | The exact threshold where numerical error alters a discrete token choice. |
| **$D(t)$** | The Propagation | The speed and severity of the autoregressive collapse following the initial error. |
